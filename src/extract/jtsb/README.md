# JTSB 抽出（未実装）

運輸安全委員会の船舶事故調査報告書 PDF から `.voyage.json` を起こす。

**実測に基づく設計メモは [`docs/jtsb-extraction.md`](../../../docs/jtsb-extraction.md) にある。
書く前に必ず読むこと。** 全角文字、正規表現が改行を跨ぐ件、列見出しが信用できない件は、
どれも一度踏んで直したもの。

## 方針

- PDF テキスト抽出は **`pdfjs-dist`**（`pdftotext` のような外部コマンドに依存しない）。
  グリフごとの x/y が取れるので、**列の切り分けを空白の数当てではなく座標で解ける**。
  今の罠の半分はこれで消える
- 対象は **Tier A**（付表に AIS 数値表がある事案）のみ。Tier B の航跡図デジタイザは別
- 抽出した各数値には**出典（該当ページと引用文字列）を付ける**。人が確認するとき、
  報告書全体ではなく引用箇所だけを読めばよくするため
- 列の意味は**値域で判定する**。見出しは補助にしか使わない
- 出力は必ず `spec/voyage.schema.json` を通し、`checkPlausibility` にかけてから書き出す

## 全自動にしない

抽出は 100% にならない。目指すのは「全自動」ではなく「**訂正が速いこと**」。
人が航跡を見れば嘘かどうかは即座に分かるので、確認と修正が入る構造のほうが正しい。
