# 海岸線（座標グリッドを地図にする）

## 何を

今の平面は水面と可変グリッドだけ（`src/render/scene.ts`）。ここに海岸線を入れて、事案の位置が
地理として読めるようにする。ラスタタイルではなく、ベクタ（GeoJSON）をローカル ENU に投影して
陸地メッシュにする。

## なぜ

再現動画を公開する前提。今の画面は座標系としては正しいが、どこの海なのかが分からない。

**素直な実装だと何が間違うか。** 「地図といえばタイル」でタイルを貼ると 2 つ壊れる。

1. `npm run build:single` は出力に外部参照が残っていたら失敗する設計。実行時に fetch する版は
   `file://` で開けず、1 枚 HTML という売りが消える
2. タイルを焼き込むと、それは「リアルタイム表示」ではなく複製になり、ライセンスの扱いが変わる。
   地理院タイルはリアルタイム表示なら出典明示のみで申請不要（承認申請 Q&A Q1-12）、動画での
   背景利用も申請不要（Q1-8）だが、ダウンロードして保存する側は複製として申請フローの判断対象

ベクタなら JSON 1 つなので `build:single` に素直に入り、実行時の取得が無い。

## どう

- 海岸線 GeoJSON を lat/lon からローカル ENU に投影する。`core/geodesy.ts` の
  `toLocalPosition` がすでにある
- ポリゴンを `THREE.Shape` にして `ShapeGeometry` で三角形化する。three.js は earcut を内蔵して
  いる（`three/src/extras/Earcut.js`）ので新規依存はゼロ
- 水面のすぐ上に置く。夜のパレットでは陸は海より暗い塊として出る

データ源は **国土数値情報（国土交通省）の行政区域データ**。出典明示で再配布可、1:25,000 相当なので
日本沿岸なら精度は十分。

比較して落としたもの:

- **Natural Earth** — パブリックドメインで一番緩く帰属表示すら要らないが、1:1000 万想定。
  3〜20 km の画面では総描誤差が大きすぎる。広域の位置図（インセット）としてなら使える
- **OpenStreetMap** — 精度は十分で世界中を覆う。動画は ODbL の Produced Work なので帰属表示だけで
  済む（share-alike がかかるのは Derivative Database だけ、4.5(b)）。ただし GeoJSON を切り出して
  このレポに置くと、そのファイル自体が Derivative Database で ODbL になり、MIT のコードと
  二本立てになる
- **海図**（海上保安庁 / 日本水路協会）— 有償・許諾必要。使わない

地理院タイルは `npm run dev` の背景としてだけ入れるなら申請不要で一番きれい。ただし
`build:single` の出力には入れない。

## どのファイル

- 新規 `src/render/coastline.ts` — GeoJSON から陸地メッシュ
- `src/render/scene.ts` — 陸を水面の上に置く。夜と昼のパレットに陸の色を足す
- `spec/voyage.schema.json` / `docs/format.md` — 海岸線をシナリオに持たせるなら
- `scripts/build-single.mjs` — 海岸線も畳む対象になるか確認する
- `test/coastline.spec.ts` — 投影と三角形化。既知の緯度経度が既知の ENU に落ちること
- `README.md` — 出典表示

## 未解決

- **海岸線をどこに置くか。** シナリオ JSON に埋める（自己完結する。事案ごとに切り出す）か、
  別ファイルにして参照する（重複しない。`build:single` が畳む対象が増える）か。1 事案ぶんだけ
  切り出せばよいので前者でも数十 KB で収まるはず——実測して決める
- **潮位。** 地形図の海岸線は満潮時の水陸境界。座礁や浅所が絡む事案では海岸線ではなく等深線が
  要る。等深線は別データで、ライセンスも別途確認（GEBCO、海上保安庁）
- **日本の外の事案。** 国土数値情報は日本沿岸で止まる。外航事案が来たら OSM に切り替えるのか、
  両対応にするのか。両対応にするならデータファイルごとにライセンスを持たせる仕組みが要る
- **海岸線より航路と灯台のほうが効くのではないか。** 「なぜその針路だったか」を読ませるのは
  航路筋・分離通航方式・灯台の位置。別 issue に切るかどうか
- **縮尺の読み。** 陸が入るとグリッドだけでは縮尺が読みにくくなる。スケールバーを足すか
