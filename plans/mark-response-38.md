# 浮標は水面をそのままなぞらない（issue #38）

## 何を

いまの `render/player.ts` は、浮標の喫水線を水面高さに、甲板を水面の傾きにそのまま合わせている。
**これは小物体極限**で、片方は妥当、もう片方は妥当でない。

### 上下動（heave）——長い波では正しく、短い波で外れる

浮体の上下動は、復原力 `ρgA`・質量 `ρAd` のばね質量系。固有角振動数は

```
ω_n² = ρgA / (ρAd) = g / d        →   T_n = 2π √(d/g)
```

（`A` は水線面積、`d` は喫水。**面積が約分で消える**ので、固有周期は喫水だけで決まる。）

| | 喫水 | T_n |
|---|---:|---:|
| pillar（胴体 3.2 m） | 1.6 m | 2.54 s |
| spar | 3.5 m | 3.76 s |
| can | 1.4 m | 2.41 s |
| 大型灯浮標 | 4.8 m | 4.40 s |

周期比 0.30（8.6 s のうねり）なら応答は 1.08 で、**水面をなぞって正しい**。
周期比 0.85（3 s の風浪）なら応答は **1.72**——水面の倍近く動く。
いまのモデルはその分だけ外れ、ページには何も出ない。

### 傾き（tilt）——外れていて、しかも一番それらしい形で外れる

いまは全部の浮標を局所傾斜に合わせて傾けている。**スパーブイは直立を保つために存在する形**で、
それが波ごとに傾く。シナリオが形を書き、形が応答を決めるのに、レンダラがそれを無視している。

## 一次情報と、無い一次情報

- **固有周期は導出できる**（上の式）。水線面積が消えるので、必要なのは喫水だけ——
  そして喫水は `marks` が既に持つ幾何から出る
- **減衰比には出典が無い。** 調べた範囲では、浮標の heave 減衰は形状と heave plate の有無で
  変わる量で、「浮標の減衰比はこれ」という定数は存在しない。**この issue で唯一、出典の無い
  入力**なので、選んだ値としてパネルに書く（波スペクトルの `TAIL_CUTOFF_FRACTION_OF_PEAK` と
  同じ扱い）
- しかも**共振点で応答は `1/(2ζ)`** に比例するので、**この選択が一番効くのは、モデルが一番
  信用できない場所**。そのことも書く

## 素直な実装だと間違うところ

### 1. 応答を「振幅の掛け算」だけにしない

減衰系の応答には**位相遅れ**がある: `φ = atan2(2ζr, 1 − r²)`。
振幅だけ掛けると、上下動と傾きが**同じ瞬間に最大**になり続ける——issue が挙げている
「一様でなさ」の4つのうち2番目（上下動と傾きの固有周期が違うので歩調が合わない）が消える。
成分ごとに利得と位相を当てれば、それは**勝手に出てくる**。

### 2. 形から応答を決めるが、形は記載とは限らない

#42 で形の出所は4値になった。**「この工具が選んだ pillar」から出した応答を、
出典の言う応答のように書かない。**

### 3. スパーの直立を「傾き 0」で済ませない

スパーは**復原力が大きく固有周期が長い**から直立して見えるのであって、傾かないのではない。
とはいえ傾きの固有周期にはバラスト（＝出典に無い）が要る。**形が階級を含意する**という
issue の指摘に従い、形ごとの傾き応答を階級として持ち、パネルがそう書く。

### 4. 「描かれた海」に乗せる規律を壊さない

#31 で決めた通り、浮標は**描かれた海**に乗る（遠方でフラットに落ちた海の上でだけ揺れる）。
応答はその手前に入る変換であって、フェードの置き換えではない。

## どのファイル

- 新規 `src/core/response.ts` — 減衰1自由度系の利得と位相遅れ。純粋な算術で、
  既知の3点（比 0 で 1・遅れ 0／共振で `1/(2ζ)`・遅れ π/2／比 → ∞ で 0・遅れ π）に当てる
- 新規 `src/actors/mark/riding.ts` — 形と高さ → 喫水 → 固有周期 → 成分ごとの応答（上下動・傾き）
- `src/render/mark.ts` の `PROPORTIONS` を `actors/mark/` へ移す（喫水は浮標の幾何であって
  描画の都合ではない。`actors/vessel/heights.ts` と同じ移動）
- `src/core/seaway.ts` — `surfaceAt` が成分ごとの変換を任意で受ける
- `src/render/scene.ts`, `src/render/player.ts` — 描かれた海に応答を通す
- `src/ui/panels.ts` — 使った応答と、減衰比が選んだ値であること

## この変更に入れないもの

- **係留の拘束**（issue の3番目）。流れがあると灯浮標は引き込まれて傾くが、
  `environment.current` を使う別の計算で、#38 の主題（波への応答）とは別の力
- **水線面での傾斜の平均化**（4番目）。117 m の波に 1.8 m の幅では効かない。
  帯域が広がる #36 で効いてくる
- **船体の動揺**（#32）。GM が報告書に無いので保留、という判断は変わらない
