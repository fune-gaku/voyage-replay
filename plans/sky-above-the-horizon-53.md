# 水平線の上にも空を描く（issue #53）

## 何を

#37 は**水面が返す空**に勾配と天体を入れたが、**水平線の上（`scene.background`）は 1 色のまま**。
しかも `palette.sky` の意味を「空の色」から「**水平線の色**」に変えて淡くしたので、
**画面の上半分が勾配の一番淡い端で塗りつぶされている**。

| | #37 前 | いま |
|---|---|---|
| 水平線上の背景 | `0x74a5dc` | `0x9dc0e6`（淡い） |
| 水面が返す空 | 同じ 1 色 | `0x9dc0e6` → `0x3d7ac4` の勾配 |

船橋視点は画角 55° なので**画面上端は水平から 27° 上**。晴天ならそこは水平線よりはっきり濃い。
平らで淡い空は霞んで見え、実際「空の色が変」という反応が出た。

さらに: **水面が返している月が、その上の空のどこにも無い**。パネルが
「ドームが無いので天体は反射の中にしか出ない」と**制限を弁解する文**を書いている状態。

## 決めたこと

### 1. 同じ関数を 2 回描く

`skyTowards` は既に「この方向の空は何色か」に答えている。水面は反射ベクトルで呼び、
**水平線の上は視線ベクトルで呼ぶ**。1 つの定義、2 つの消費者——このレポが繰り返し取っている形。

### 2. 勾配と天体を分けられるようにする

いまの `skyTowards` は `uSeaSlope < 0`（海の記載なし）で**天体ごと落とす**。
これは「記載の無い海を鏡にすると凪を主張する」ための門で、**空そのものには当てはまらない**
——月は海が記載されていようがいまいが空にある。

なので GLSL を 2 つに割る:

- `skyGradient(dir)` ——地平と天頂の間の勾配
- `bodyGlow(dir, width)` ——天体のローブ（幅は呼び手が決める）

水面: `skyGradient(back) + (海があれば) bodyGlow(back, lobeWidth(carried, radius))`
空: `skyGradient(dir) + bodyGlow(dir, radius)` ——**海の傾斜は関係ない。空の天体は視直径のまま**

### 3. 平面図は 1 色のまま

海図は空ではない。照明・地図の乗算色・グリッド・glitter と同じ判断（`setDiagramView`）。

### 4. 霧は当てない、が、当てないことを書く

`buildFog` の far は視程が無ければ「表示範囲の 3 倍」なので、ドームを霧に入れると
**どのシナリオでも空が霧色 1 色**に戻る。ドームは霧の外に置く。
ただし**霧の上に晴れた空が見えるのは霧ではない**ので、パネルがそう言う
（`restrictedSky` が既に「昼として描く」という同種の宣言をしている）。

## 素直な実装だと間違うところ

1. **水平線の継ぎ目。** 水面はグレージング角でほぼ空の色そのものを返すので、
   **水平線のすぐ上と下で色が違ったら一目で分かる**。両方が同じ `skyGradient` を呼ぶこと
2. **ドームを霧に入れる。** 上記のとおり、空が霧色 1 色に戻って何も直らない
3. **ドームを原点に置く。** 眼が数 km 動くシナリオでは、有限半径のドームは**視差で回る**。
   眼に追随させる（半径に対して眼高は無視できる）
4. **カメラの far より遠くに置く。** 船橋カメラは far 80 km。それを超えるとクリップされて
   背景が抜ける
5. **`depthWrite` を切らない。** 空が水面や船体を隠す
6. **パネルの文が古くなる。** 「ドームが無いので天体は反射の中にしか出ない」は嘘になる。
   **直したらページ全体でその語を grep する**（このレポの規律）

## 触るもの

- `src/render/sky.ts`——GLSL を `skyGradient` と `bodyGlow` に割り、ドームを組む関数を足す
- `src/render/waves.ts`——反射側の呼び方を合わせる
- `src/render/scene.ts`——ドームをシーンに入れ、眼に追随させ、平面図では隠す
- `src/ui/panels.ts`、`docs/domain-notes.md`、`CLAUDE.md`

## やらないこと

**物理的な空モデル（Preetham / Hosek）**。濁度を誰も書いていないので入れられない、というのは
#37 で既に出した結論。ここで変えるのは**勾配をどこに描くか**であって、勾配そのものではない。
