# 船の運動モデル（直線補間の置き換え）

## 何を

`src/core/track.ts` の `sampleAt()` は標本間を直線で結んでいる。これを、船として成立する
運動に置き換える。置き場所は `src/actors/vessel/motion.ts`（`core/` に船の概念を入れない）。

## なぜ

視聴者が「しらける」のはポリゴンの粗さではなく運動の嘘。具体的には 3 つ。

1. **舵の効き遅れが無い。** 舵を切った瞬間に回頭が始まり、戻した瞬間に止まる
2. **旋回を惰性で引きずらない。** 商船は全速力舵一杯で船長の 2.5〜5 倍の径で回る
3. **船首が進行方向を向いたまま。** 実際は偏角ぶんずれる。直線補間だと船が横滑りして見える

1 分間隔の標本を直線で結ぶと、船を扱ったことがある人には一目で嘘だと分かる。
このツールの視聴者はまさにその層を含む。

## どう

一次遅れ（野本）モデル: `T·ṙ + r = K·δ`（r = 回頭角速度、δ = 舵角、T = 時定数、K = 旋回力指数）。

問題は**舵角が観測されていない**こと。報告書にあるのは位置・針路・速力だけ。なので順方向に
解くのではなく、**観測された針路変化を満たす舵角の履歴を逆算する**（各区間で δ を定数と仮定し、
区間端の針路が合うように解く）。K と T は船長と速力から推定する——文献値がなければ
`T ≈ L/V × 定数`, `K ≈ V/L × 定数` の形で近似し、その定数はドキュメントに明記する。

偏角は、旋回中は `β ≈ 回頭角速度 × 旋回中心から船首までの距離 / V` で近似できる。
潮流ぶんは `environment.current` があれば COG と HDG の差から分離できるが、v1 では扱わない。

## どのファイル

- 新規 `src/actors/vessel/motion.ts` — モデル本体と係数の推定
- `src/core/track.ts` — `sampleAt()` に補間戦略を差せるようにする。既定は現状の直線のまま残し、
  呼び出し側が船の運動モデルを渡せる形にする（`core/` は船を知らない）
- `test/motion.spec.ts` — 既知の旋回試験値（旋回径が船長の何倍か）で検証
- `docs/domain-notes.md` — 採用した係数と、その出どころ

## 未解決

- **係数の出どころ。** 文献値を引くのか、事案ごとに観測から当てるのか。前者なら出典を明記する。
  後者なら、当てた係数自体が推定なので `derivation` の考え方をどう適用するか
- **標本が粗い事案**（10 分間隔など）で逆算が破綻しないか。破綻するなら、
  そういう区間は素直に `interpolated` のまま直線で置く判断もある
- **`headingDegreesTrue` が無い船**（簡易型 AIS）でどうするか。COG しか無いので偏角を
  分離できない。船首方位を推定するなら、それは `inferred` であって `measured` ではない
